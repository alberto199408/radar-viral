# Radar Viral

App para encontrar los videos más virales de YouTube por tema, idioma y país, con estudio completo de cada búsqueda.

**Abrir e instalar:** https://alberto199408.github.io/radar-viral/

En el teléfono (Chrome): abre el enlace → menú ⋮ → **Instalar aplicación**.

Archivos:
- `index.html` — la app completa. La configuración del dueño (conexión con YouTube e inicio de sesión con Google) está arriba del código, en `CONFIG`.
- `manifest.webmanifest`, `sw.js`, `icon-*.png` — para instalarla como aplicación.
- `privacidad.html` — política de privacidad.

Usa los Servicios de API de YouTube: https://www.youtube.com/t/terms
